# Design

## User Interface design

The wireframe below presents the user interface design for the Car Park Finder application. It portrays the structure of the parking website by organising the key components such as the app overview, header navigation bar and interactive map with clickable location markers and parking information table sourced from Bristol Open Dataset, user review and current issues. This design emphasises clarity, accessibility and a smooth user experience ensuring that essential information is easy to locate and interact with.
