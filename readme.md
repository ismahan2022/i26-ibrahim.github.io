# Car Park App

### Brief Project Outline

This project aims to develop a car park application for drivers in Bristol, helping them travel more easily around the city and reducing stress when searching for parking. The application uses data from the Bristol Open Dataset, which provides key parking information such as locations and details for each car park. By offering real‑time updates and clear information on pricing, availability, and operating hours, the app enables drivers to make informed decisions before travelling. The system also includes an interactive map with clickable location icons to make navigation easier. The app also provides current issues and reviews. Overall, the app supports more efficient route planning, reduces congestion, and improves the driving experience across Bristol.
